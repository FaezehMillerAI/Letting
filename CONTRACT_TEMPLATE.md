### 1. BACKGROUND
The Provider has developed proprietary artificial intelligence software known as **"LettingsPulse Exeter"** (the "Platform"), designed to automate student tenant lead qualification, real-time property inventory matching, and statutory viewing scheduling via WhatsApp and Web Chat interfaces. The Client wishes to engage the Provider to implement, host, and maintain the Platform for the Client’s property portfolio in accordance with the terms below.

---

### 2. SERVICES PROVIDED & IMPLEMENTATION
2.1 **Initial Setup & Onboarding:**
   - Configuration of the LettingsPulse AI Agent with the Client’s branding, property portfolio (HMOs/student housing), pricing parameters (£pppw, bills status), and campus proximity rules.
   - Integration with the Client’s WhatsApp Business phone number and team calendar (Google Calendar / Cal.com / Outlook).
   - Deployment of the embeddable student web chat widget onto the Client’s website.

2.2 **Ongoing Services:**
   - 24/7 cloud hosting, server infrastructure, and database maintenance.
   - Continuous LLM API and WhatsApp Business gateway connectivity.
   - Ongoing system updates, bug fixes, and prompt optimization.
   - Technical support via email/phone with standard response times under 24 hours.
